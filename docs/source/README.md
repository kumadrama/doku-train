# 原始资料登记

本目录保存用户提供的原始设计文档或原样导出。原始文件默认只读；Agent 的整理、推断和目标
设计只能写入 `docs/architecture/` 或对应 Spec，不能反写原文。

## 登记规则

新增原始资料时记录：

- 来源名称与稳定地址或 token；
- 获取日期；
- 原始文件名与格式；
- 如来源支持版本，记录 revision/version；
- 是否允许后续同步，以及同步时是否需要用户确认。

当前尚未导入原始设计文件。Finder 与相邻 Doku 仓库只作为代码/约束参考，已在 architecture
文档的 `Source:` 中按仓库 revision 登记，不复制到本目录。
