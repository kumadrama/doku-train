# 任务族与模型身份

部署时，doku-iac 的 model_monitoring 根模块导出 tf_daily_deployment。每个任务族声明运行角色、域和密封产物位置。FYP 与 Idea 原有失败报警保留原通知，新增任务族复用失败检测模块与共享通知路由。IAM 跟随实际生产者角色。

训练仓从当前任务定义读取任务族和角色，校验已应用的登记信息。配置原文按字节写出，部署绑定的 monitoring 子对象承载模型名、任务族与事件目的地。执行器对照 ECS 元数据的 Family；训练容器在选模记录上冻结该值。投递原始密封事件，重试可复用相同事件 ID 和内容。未接入时建立的 Idea 训练产物直接跳过。

监控目录保存任务族。旧 FYP 图表用已验证的 Endpoint 归属读取已有日志。新模型按任务族归域，每个任务图对各模型独立查询数据日的最后一次完整选模记录。每模型发布状态、训练作业以及日期筛选仍然可查。
